🎙 Проєкт JustSay: Концепція локально-орієнтованого AI-хабу🌟 Візія продуктуJustSay — це персональна операційна система для обробки голосу. Вона перетворює хаотичний аудіопотік (думки, мітинги, промпти) у структуроване знання, забезпечуючи користувачу повний мануальний контроль над приватністю та швидкістю через гібридну архітектуру (Cloud API / Local AI).🎯 Основні сценарії використання (Business Scenarios)1. "Instant Prompt" (Швидка диктовка)Мета: Заміна клавіатурного вводу при роботі з LLM (Claude, Gemini, ChatGPT).Вимога: Мінімальна затримка (Latency) від завершення мовлення до появи тексту в буфері обміну. Текст має бути автоматично очищений від слів-паразитів та граматично виправлений.2. "Project Memory" (Архівування зустрічей)Мета: Створення "вічної пам'яті" проєкту в Obsidian.Вимога: Запис системного звуку (співрозмовники) та мікрофона. Результат — детальний протокол зустрічі (Summary, Decisions, Action Items) з автоматичним лінкуванням тем у базі знань.3. "Structured Thoughts" (Голосовий менеджер знань)Мета: Перетворення "потоку свідомості" у конкретні формати даних.Вимога: Можливість обрати шаблон обробки (напр., "Створи список тасків", "Напиши структуру статті", "Згенеруй JSON об'єкт").🧠 Інтелектуальний рівень (Model Strategy)Користувач має мануальний перемикач [Cloud ☁️ / Local 🏠] для кожного модуля.Стек моделей (План 2026):ЗадачаРежим Google/Groq).🛠 Інструкція для AI (Контекст для розробки)При написанні коду для цього проєкту, використовуй модульний підхід. Backend на Python має бути агностичним до того, яка модель обрана — він просто виконує контракт (Audio In -> Text Out). Frontend на TypeScript має бути максимально легким, фокусуючись на системних подіях Windows та візуалізації стану обробки. Всі налаштування моделей мають бути винесені в окремий конфігураційний шар.
